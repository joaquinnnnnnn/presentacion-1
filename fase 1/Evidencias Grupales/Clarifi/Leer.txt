# Clarifi Finanzas

Aplicación web para registrar y visualizar ingresos y gastos, con base de datos PostgreSQL integrada y lista para ejecutar mediante Docker.

## Requisitos
- Node.js 18 o superior
- Docker Desktop
- Git

## Instalación rápida

1. Clonar el proyecto
   git clone https://github.com/<tu-usuario>/clarifi.git
   cd clarifi

2. Crear archivo de entorno
   cp .env.example .env

3. Levantar base de datos
   cd docker
   docker compose up -d
   cd ..

4. Instalar dependencias y ejecutar
   npm install
   npm run dev

5. Abrir en el navegador
   http://localhost:3000

## Conexión base de datos
- Host: localhost  
- Puerto: 5432  
- Usuario: postgres  
- Contraseña: Clarifi2025  
- Base de datos: clarifi  

## Archivos clave
- db/schema.sql → crea las tablas y tipos.
- db/seed.sql → inserta categorías y transacciones iniciales.
- lib/db.ts → conexión de la app con PostgreSQL.
- docker/docker-compose.yml → configuración Docker.

## Persistencia
Los datos se guardan en el volumen `postgres_data`.  
Solo se eliminan si ejecutas `docker compose down -v`.
